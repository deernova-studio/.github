# HandyDesk 隐私政策
更新日期：2026 年 11 月 7 日
开发者：DeerNova Studio

HandyDesk 是连接你授权的 Mac 的远程桌面客户端。应用没有账号注册、广告、追踪或分析服务，DeerNova Studio 不通过应用收集你的个人数据。

本机保存
你添加的电脑名称、地址、账户短名称、连接时间和偏好保存在设备本地。只有你开启「记住密码」时，密码才会保存到本机钥匙串，且仅在设备解锁时可用，不通过 iCloud 钥匙串同步。系统设备备份可能包含电脑列表和偏好，取决于你的系统备份设置。

远程连接
应用直接连接你填写的电脑地址。登录凭据用于该电脑的认证，桌面画面和输入事件在设备与该电脑之间传输，不经过 DeerNova Studio 的服务器。HandyDesk 不在应用中录制或持久保存远程画面。应用不内置 VPN；远程访问建议通过你自行配置的 Tailscale 加密网络，VNC 桌面流量本身不提供端到端加密。Tailscale 的数据处理遵循其自身隐私政策。

剪贴板
应用不会在后台自动读取或同步手机剪贴板。你主动使用系统粘贴按钮或粘贴菜单时，选中的文字进入编辑框；只有你点击发送，文字才发送到当前连接的电脑。

管理和删除
在电脑编辑页关闭「记住密码」并保存可删除保存的密码。删除电脑会同时删除该电脑的配置和保存的密码。卸载前如需清除钥匙串密码，请先在应用内删除电脑；iOS 钥匙串条目可能在卸载后仍保留。断开连接后，应用不再接收桌面画面或发送操作。

支持与第三方
应用内的 VNC 和加密依赖用于连接和认证，不包含广告或遥测 SDK。Apple 的商店、诊断与设备备份服务，以及你自行使用的 Tailscale，按各自政策处理数据。
隐私及使用问题可通过 DeerNova Studio 的 GitHub 支持入口提交：https://github.com/deernova-studio/.github/issues
提交支持请求时请不要附上密码、密钥或包含个人信息的远程桌面截图。GitHub 提交的内容遵循 GitHub 的隐私政策，公开问题可被其他人查看。
