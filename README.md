# DeerNova Studio organization profile

This repository maintains the public [DeerNova Studio overview](https://github.com/deernova-studio).

- `profile/README.md`: content displayed on the organization's Overview page.
- `profile/assets/deernova.png`: approved black logo on a white background.

Changes to `profile/README.md` on `main` update the public overview. Keep private project details, credentials, personal contact information, and internal deployment records out of this repository.
