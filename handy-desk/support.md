# HandyDesk 支持

HandyDesk 是原生 iPhone / iPad 远程桌面客户端，用于查看并操作你授权的 Mac。支持 iOS / iPadOS 17 及以上。

## 开始使用

1. 在 Mac 的「系统设置 → 通用 → 共享」打开屏幕共享，并允许你的本地账户访问。
2. 确保 iPhone / iPad 与 Mac 网络互通。远程访问建议两端连接你自己配置的 Tailscale 网络；同一可信局域网也可以使用 Mac 的局域网地址。
3. 在 HandyDesk 添加电脑，填写地址、端口 `5900` 和 Mac 账户短名称。
4. 输入 Mac 登录密码。可选择记住密码，凭据仅保存在本机钥匙串。

HandyDesk 不提供 VPN。VNC 桌面流量本身不提供端到端加密，请勿把屏幕共享端口直接暴露到公网。

## 常用操作

- 轻点点击；双指轻点右键；长按后移动拖动。
- 双指滑动滚动电脑页面。默认模式下，单指移动的是放大后的画面。
- 双指捏合缩放；双箭头按钮恢复完整画面。
- 底部「画面 / 鼠标」切换画面平移和触控板操作。
- 打开键盘后，用手机 / 电脑图标切换输入方式。手机输入模式下建议 Mac 切到 ABC。
- 「发送文字」中的系统粘贴按钮可把手机复制的文字插入编辑框，再发送到 Mac。

## 常见问题

连接失败时，检查 Mac 已开机、屏幕共享已开启、地址可达，并确认填写的是 Mac 本地账户及密码。Tailscale 不会替你启用屏幕共享。

应用进入后台会断开连接；返回后可重新连接。当前不支持音频、文件传输、自动发现、远程分辨率或帧率设置。
